
# Component: `Content`

This component is used to send content to the client, such as HTML pages, files, or binary data or it can also be used to set the content type of
 the response.

## Component Signature

```
<bx:Content type=[string]
deleteFile=[boolean]
file=[string]
variable=[any]
reset=[boolean] />
```

### Attributes


| Atrribute | Type | Required | Description | Default |
|----------|------|----------|-------------|---------|
| `type` | `string` | `false` |  |  |
| `deleteFile` | `boolean` | `false` |  | `false` |
| `file` | `string` | `false` |  |  |
| `variable` | `any` | `false` |  |  |
| `reset` | `boolean` | `false` |  | `true` |
