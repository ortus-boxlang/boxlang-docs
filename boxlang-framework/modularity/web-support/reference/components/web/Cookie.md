
# Component: `Cookie`

Defines web browser cookie variables, including expiration and security options.

## Component Signature

```
<bx:Cookie name=[string]
value=[string]
secure=[boolean]
httpOnly=[boolean]
expires=[any]
samesite=[string]
path=[string]
domain=[string]
encodevalue=[boolean] />
```
