
# Component: `Header`

Generates custom HTTP response headers to return to the client.

## Component Signature

```
<bx:Header name=[string]
value=[string]
charset=[String]
statusCode=[integer]
statusText=[string] />
```

### Attributes


| Atrribute | Type | Required | Description | Default |
|----------|------|----------|-------------|---------|
| `name` | `string` | `false` |  |  |
| `value` | `string` | `false` |  |  |
| `charset` | `String` | `false` |  | `UTF-8` |
| `statusCode` | `integer` | `false` |  |  |
| `statusText` | `string` | `false` |  |  |
