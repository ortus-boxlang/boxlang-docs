# Function: `DayOfWeekAsString`

Returns the full day of the week name of a date object. Note that the behavior of this function is not localized, as
                             Sunday is always considered to be the first day of the week.

## Method Signature

```
DayOfWeekAsString(date=[any], timezone=[string], locale=[string])
```

### Arguments


| Argument | Type | Required | Description | Default |
|----------|------|----------|-------------|---------|
| `date` | `any` | `false` | The numeric integer to extract the day of week or month from. |  |
| `timezone` | `string` | `false` |  |  |
| `locale` | `string` | `false` |  |  |
