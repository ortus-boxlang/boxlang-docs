# BoxLang AI

{% hint style="info" %}
BoxLang AI now has its own section in this book.
{% endhint %}

{% content-ref url="../../boxlang-ai/" %}
[boxlang-ai](../../boxlang-ai/)
{% endcontent-ref %}

The `bx-ai` module provides a unified, fluent API for chat, streaming, structured output, agents, tools, memory, RAG, MCP, audio, images, web search, and the governance controls enterprises need.

## 📦 Installation

```bash
install-bx-module bx-ai
```

With CommandBox:

```bash
box install bx-ai
```
