# Components

UI and AJAX components for BoxLang UI Compatibility Module.

## Components

* [AjaxImport](AjaxImport.md) - Imports JavaScript and CSS files for AJAX features
* [AjaxProxy](AjaxProxy.md) - Creates an AJAX proxy for client-server communication
* [Div](Div.md) - Generates a dynamic HTML div element
* [Grid](Grid.md) - Generates a data grid with sorting and pagination
* [GridColumn](GridColumn.md) - Defines a column in a data grid
* [GridRow](GridRow.md) - Defines a row in a data grid  
* [GridUpdate](GridUpdate.md) - Updates grid data via AJAX
* [Layout](Layout.md) - Generates layout containers (tab, accordion, border, etc.)
* [LayoutArea](LayoutArea.md) - Defines areas within a layout container
* [Pod](Pod.md) - Generates a pod (content container with title bar)
* [Tooltip](Tooltip.md) - Adds tooltip functionality to elements
