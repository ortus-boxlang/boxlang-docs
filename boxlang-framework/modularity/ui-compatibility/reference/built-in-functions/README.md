# Built-in Functions

This section contains documentation for UI and AJAX related built-in functions.

## Functions

* [AjaxLink](AjaxLink.md) - Creates an AJAX link that loads content into a target element
* [AjaxOnLoad](AjaxOnLoad.md) - Executes JavaScript code when the page finishes loading
* [QueryConvertForGrid](QueryConvertForGrid.md) - Converts query data to a format suitable for grid components
