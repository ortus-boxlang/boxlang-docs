# Object Marshalling Events

These events are fired during object (de)serialization operations.

| Event Name                        | Data | Description                       |
| --------------------------------- | :--: | --------------------------------- |
| `beforeObjectMarshallSerialize`   |      | Before an object is serialized.   |
| `afterObjectMarshallSerialize`    |      | After an object is serialized.    |
| `beforeObjectMarshallDeserialize` |      | Before an object is deserialized. |
| `afterObjectMarshallDeserialize`  |      | After an object is deserialized.  |
