# Datasource Service Events

These events occur around the lifecycle of datasources and the datasource service.

| Event Name                    | Data | Description                             |
| ----------------------------- | :--: | --------------------------------------- |
| `onDatasourceServiceStartup`  |      | When the datasource service starts up.  |
| `onDatasourceServiceShutdown` |      | When the datasource service shuts down. |
| `onDatasourceStartup`         |      | When a datasource is started.           |
