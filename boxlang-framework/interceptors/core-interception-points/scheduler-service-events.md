# Scheduler Service Events

These events occur around the management of multiple schedulers in the system.

| Event Name                   | Data | Description                            |
| ---------------------------- | :--: | -------------------------------------- |
| `onSchedulerServiceStartup`  |      | When the scheduler service starts up.  |
| `onSchedulerServiceShutdown` |      | When the scheduler service shuts down. |
| `onAllSchedulersStarted`     |      | After all schedulers have started.     |
| `onSchedulerRemoval`         |      | When a scheduler is removed.           |
| `onSchedulerRegistration`    |      | When a scheduler is registered.        |
