# Archive Functions

BoxLang provides built-in functions for creating and extracting archives.

- [`compress()`](Compress.md) creates ZIP, gzip, bzip, and tar-family archives.
- [`extract()`](Extract.md) extracts supported ZIP, gzip, bzip, and tar-family archives.
- [`isZipFile()`](IsZipFile.md) checks whether a path is a ZIP archive.

For practical workflows and the `<bx:zip>` component, see [Compression and Archives](../../../../boxlang-framework/file-handling/compression.md).
