# Function: `Ascii`

Determine the ASCII value of a character

## Method Signature

```
Ascii(string=[string])
```

### Arguments


| Argument | Type | Required | Description | Default |
|----------|------|----------|-------------|---------|
| `string` | `string` | `true` | The string containing a single character to determine the ASCII value. |  |
