# Function: `Sin`

Returns the sine of a number

## Method Signature

```
Sin(number=[numeric])
```

### Arguments


| Argument | Type | Required | Description | Default |
|----------|------|----------|-------------|---------|
| `number` | `numeric` | `true` | The number to calculate the sine of, entered in radians. |  |
