# Function: `Asin`

Returns the arcsine (inverse sine) of a number

## Method Signature

```
Asin(number=[double])
```

### Arguments


| Argument | Type | Required | Description | Default |
|----------|------|----------|-------------|---------|
| `number` | `double` | `true` | The number to calculate the arcsine of |  |
