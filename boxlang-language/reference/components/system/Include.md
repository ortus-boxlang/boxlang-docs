
# Component: `Include`

I include a template into the current template

## Component Signature

```
<bx:Include template=[string] />
```

### Attributes


| Atrribute | Type | Required | Description | Default |
|----------|------|----------|-------------|---------|
| `template` | `string` | `true` |  |  |

## Examples

### Tag Syntax




```java
<bx:include template="mypage.bxm">
```
