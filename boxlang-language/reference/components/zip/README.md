# ZIP Components

Use `<bx:zip>` for ZIP archive operations such as zipping, unzipping, listing, reading, and deleting entries. Use `<bx:zipParam>` to add in-memory content or configure source entries.

- [`<bx:zip>`](Zip.md)
- [`<bx:zipParam>`](ZipParam.md)

See [Compression and Archives](../../../../boxlang-framework/file-handling/compression.md) for workflows and format support.
